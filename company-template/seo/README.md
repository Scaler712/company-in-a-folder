# SEO and AI search

What the search jobs read and write.

- `seo/pages.md`: every page that matters, one line each
- `seo/keyword-map.md`: one main search term per page, so two pages never fight for the same one
- `seo/ai-questions.md`: the questions buyers ask AI assistants, and a dated log of who got named in the answers

Every number in these files has a source and a date. A guess is written as a guess.
